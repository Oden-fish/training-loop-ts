# 既定のループプロンプト（`/loop` を引数なしで実行したときに使われる）

このリポジトリのキューを1周ぶん進めてください。**人間には質問しないこと。**

1. まず `/loop-status` 相当の確認を行い、現在地を把握する。
2. 次の優先順位で、**1周につき1つだけ**着手する:
   1. `agent:wip` の Issue が残っていれば、その続きを `/issue-loop <番号>` で再開する
   2. オープンな PR で CI が赤いものがあれば、`ci-doctor` で診断して直す
   3. オープンな PR で、現在の HEAD に対するレビューが無いものがあれば `/review-pr <番号>`
   4. Phase 2 以降で、APPROVE 済み・CI 緑の PR があれば `/land-pr <番号>`
   5. `agent:ready` の Issue があれば、最も古いものに `/issue-loop` で着手する
3. どれも該当しなければ「キューは空です」と1行だけ返して、何も新しいことを始めない。

## やってはいけないこと

- キューに無い作業を自分で始める（「ついでにリファクタ」「テストを増やしておく」など）
- `agent:blocked` の Issue を勝手に再開する（人間がラベルを `agent:ready` に戻すまで触らない）
- 1周で複数の Issue に手を出す
- 詰まったのに `agent:blocked` を付けずにターンを終える
